# Android Exam Practice 
This project is a university assignment focused on practicing Android development concepts including API simulation, maps integration, and notifications.

## Goal
The objective was to simulate a backend API and learn how to handle client–server communication patterns without a real remote server. The project also served as hands-on practice with Android platform features such as maps and push notifications.

## Features
- Simulated REST API (mock/fake backend)
- Map integration and location display
- Local notifications
- Basic UI interaction and data flow
